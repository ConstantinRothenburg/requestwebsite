## Versioning

We follow [Semantic Versioning](https://semver.org/):

- **Major** (2.0.0): Breaking changes
- **Minor** (2.1.0): New features, backward compatible
- **Patch** (2.0.1): Bug fixes
- **Pre-release** (2.0.0-alpha.1): Development versions
